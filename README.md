# 🏢 AI Real Estate Investment Advisor

A full-stack Web Application built using **Django** and **Django REST Framework (DRF)** that helps real estate buyers and investors make data-driven decisions. The platform leverages the **Cohere AI API (`command-r-08-2024`)** to automatically generate comprehensive investment reports, risk assessments, and negotiation strategies for properties.

---

## ✨ Key Features
- **Property Listing & Management:** Users can post, browse, and manage detailed property listings with location, price, and specs.
- **AI Investment Insights:** Integrated Cohere AI model to evaluate risk score, market trends, and buyer negotiation tips.
- **User Authorization & Roles:** Clean multi-user architecture separating buyer inquiries and owner listings.
- **RESTful Architecture:** DRF endpoints handling automated task processing and data serialization.
- **Responsive UI:** Styled using **Bootstrap 5** for seamless mobile and desktop experience.

---

## 🛠️ Tech Stack
- **Backend:** Python, Django, Django REST Framework
- **Frontend:** HTML5, CSS3, JavaScript, Bootstrap 5
- **Database:** SQLite
- **AI / LLM Integration:** Cohere API (`command-r-08-2024`)
- **Version Control:** Git & GitHub
